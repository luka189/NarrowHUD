    Put it in the game
    
    
      
      
    1. In the game, press F9 › NarrowHUD › Position: Custom. NarrowHUD writes a layout file the first time.
      2. 
      
    2. Open %APPDATA%\Arrowhead\Helldivers2 (paste it into File Explorer's address bar) and open
        chef_data_luka189_2fnarrowhud__layout.lua  in Notepad.
        
      The one ending in __layout.lua, not __learned.lua next to it: that's what NarrowHUD has learned about your weapons, and it rewrites it while you play.
      3. 
      
    3. Replace everything in it with the copied file and save (Ctrl+S, not "Save as": Notepad can make it …layout.lua.txt, which the game never reads; File Explorer's View › File name extensions shows it).
      4. 
      
    4. Back in the game, press the key set in F9 under Read the layout file again (it has no key until you pick one; "layout file read again" shows on screen when it works), or start a mission.
